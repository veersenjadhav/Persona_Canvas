# Preview Project Workflow

Follow these steps to launch and preview the Persona Canvas Next.js application locally:

1. **Start the Development Server**
   ```bash
   npm run dev
   ```
   *(By default, this runs `next dev --turbopack -p 9002`)*

2. **Access the Preview**
   - Open [http://localhost:9002](http://localhost:9002) in your browser.
